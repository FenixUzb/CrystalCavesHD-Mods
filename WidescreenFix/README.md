# Crystal Caves HD — Widescreen Fix

Неофициальный widescreen fix версии 0.2.0 для Crystal Caves HD 1.1.7.

## Что делает

- отключает принудительное соотношение 16:10 только во время игрового процесса;
- сохраняет вертикальный обзор и расширяет видимую область по горизонтали (Hor+);
- пересчитывает границы камеры после смены разрешения;
- растягивает зелёную рамку завершения уровня на всю ширину игрового поля;
- позволяет клавишей `F10` мгновенно переключаться между Hor+ и исходным режимом 16:10;
- оставляет главное меню, сюжетные экраны и заставки в исходном формате 16:10;
- ограничивает максимальный обзор безопасным соотношением сторон карты.

Редактор уровней не изменяется: он уже поддерживает ультраширокий экран.

## Установка

Требуется Steam-версия Crystal Caves HD **1.1.7, Windows x64**.

1. Закройте игру.
2. Если BepInEx 5 ещё не установлен, скачайте официальный
   [BepInEx 5.4.23.5 для Windows x64](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip) и распакуйте его в папку
   с `Crystal Caves HD.exe`. Запустите игру один раз и закройте её.
3. Распакуйте ZIP мода в ту же папку игры, согласившись на объединение папок.
4. Запустите игру из Steam обычным способом.

В ZIP мода находятся папка `BepInEx/plugins` и документация.
**Сам загрузчик BepInEx в ZIP мода не включён.** Если он уже установлен,
повторно устанавливать его не требуется. Все три мода можно устанавливать вместе.

## Настройка

После первого запуска создаётся файл:

`BepInEx/config/local.crystalcaveshd.widescreen.cfg`

Параметр `MaximumAspectRatio` по умолчанию равен `3.2`. На экранах шире этого значения сохраняются небольшие боковые поля, чтобы камера не показывала пространство за пределами карты.

`StartInClassicMode` включает исходный формат 16:10 при запуске уровня. `ToggleShortcut` задаёт клавишу переключения; по умолчанию это `F10`.

## Удаление

Удалите:

`BepInEx/plugins/CrystalCavesHD.Widescreen/CrystalCavesHD.Widescreen.dll`

## Совместимость

- игра: Crystal Caves HD 1.1.7;
- Windows x64;
- BepInEx 5.4.23.5.
