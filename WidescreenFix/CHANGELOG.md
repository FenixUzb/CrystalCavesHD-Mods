# История изменений

## 0.2.0 — 2026-09-01

- добавлен Classic Mode с исходным игровым полем 16:10;
- `F10` переключает Classic Mode и Hor+ без перезапуска уровня;
- добавлены параметры `StartInClassicMode` и `ToggleShortcut`.

## 0.1.1 — 2026-09-01

- зелёная рамка завершения уровня теперь динамически подстраивается под ширину игрового GUI;
- боковые границы рамки перемещаются к фактическим краям широкого экрана;
- верхняя граница рамки растягивается между боковыми границами.

## 0.1.0 — 2026-08-31

- первый тестовый релиз;
- Hor+ во время игрового процесса;
- сохранение исходного 16:10 для меню и сюжетных экранов;
- пересчёт границ камеры при смене разрешения;
- безопасное ограничение максимального соотношения сторон.
