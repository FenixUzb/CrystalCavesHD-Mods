# История изменений

## 0.1.1 — 2026-09-01

- панель больше не наследует внутреннее масштабирование IMGUI игры;
- ширина, высота и размер шрифта теперь соответствуют реальным экранным пикселям;
- устранено обрезание списка достижений на широком экране.

## 0.1.0 — 2026-09-01

- первый тестовый релиз;
- живой прогресс кристаллов текущего уровня;
- сводка эпизода и список непройденных уровней;
- прогресс достижений;
- постраничный просмотр всех неполученных достижений клавишей `F8`;
- переключение панели клавишей `F9`.
