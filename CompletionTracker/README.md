# Crystal Caves HD — Completion Tracker

Неофициальный трекер прогресса версии 0.1.1 для Crystal Caves HD 1.1.7.

## Возможности

- текущие обычные и тайные кристаллы уровня;
- завершённые и пропущенные уровни текущего эпизода;
- сохранённое количество обычных и тайных кристаллов эпизода;
- общий прогресс достижений;
- постраничный список всех неполученных достижений и числовой прогресс;
- `F9` показывает или скрывает панель.
- `F8` открывает следующую страницу неполученных достижений.

Игра сохраняет количество тайных кристаллов, но не идентификаторы и координаты каждого найденного кристалла. Поэтому трекер может показать, сколько тайных кристаллов пропущено, но не их точное расположение.

## Установка

Требуется Steam-версия Crystal Caves HD **1.1.7, Windows x64**.

1. Закройте игру.
2. Если BepInEx 5 ещё не установлен, скачайте официальный
   [BepInEx 5.4.23.5 для Windows x64](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip) и распакуйте его в папку
   с `Crystal Caves HD.exe`. Запустите игру один раз и закройте её.
3. Распакуйте ZIP мода в ту же папку игры, согласившись на объединение папок.
4. Запустите игру из Steam обычным способом.

В ZIP мода находятся папка `BepInEx/plugins` и документация.
**Сам загрузчик BepInEx в ZIP мода не включён.** Если он уже установлен,
повторно устанавливать его не требуется. Все три мода можно устанавливать вместе.

## Настройка

После первого запуска создаётся файл:

`BepInEx/config/local.crystalcaveshd.completiontracker.cfg`

В нём можно изменить клавишу, начальную видимость, ширину и положение панели, а также количество показываемых достижений.

## Удаление

Удалите папку:

`BepInEx/plugins/CrystalCavesHD.CompletionTracker`
