# Crystal Caves HD — русский перевод

Неофициальный текстовый русификатор версии 0.2.11 для Steam-версии Crystal Caves HD 1.1.7 (Windows x64).

## Что переведено

- главное меню, настройки, выбор эпизода и сложности;
- сюжет трёх оригинальных эпизодов и Episode 4;
- игровые подсказки, сообщения и динамические бонусы;
- достижения и статистика;
- редактор уровней, названия объектов, врагов и предметов;
- посимвольный вывод бортовых журналов;

В словаре 446 записей. Аудит покрывает 386 из 386 основных строк и 49 из 49 пользовательских названий редактора. Ещё восемь видов сообщений с изменяемыми параметрами переводятся динамически. Дополнительный сырой просмотр всех девяти сцен проверяет 41 длинную сюжетную строку, включая записи, не видимые стандартному Unity-аудиту.

## Установка

Требуется Steam-версия Crystal Caves HD **1.1.7, Windows x64**.

1. Закройте игру.
2. Если BepInEx 5 ещё не установлен, скачайте официальный
   [BepInEx 5.4.23.5 для Windows x64](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x64_5.4.23.5.zip) и распакуйте его в папку
   с `Crystal Caves HD.exe`. Запустите игру один раз и закройте её.
3. Распакуйте ZIP мода в ту же папку игры, согласившись на объединение папок.
4. Запустите игру из Steam обычным способом.

В ZIP мода находятся папка `BepInEx/plugins` и документация.
**Сам загрузчик BepInEx в ZIP мода не включён.** Если он уже установлен,
повторно устанавливать его не требуется. Все три мода можно устанавливать вместе.

## Удаление

Запустите `Uninstall-RussianTranslation.ps1` из папки игры или удалите только:

`BepInEx\plugins\CrystalCavesHD.Russian`

Сценарий намеренно оставляет BepInEx: он может использоваться другими модами. Если BepInEx был установлен исключительно для этого перевода, его загрузчик можно удалить отдельно после проверки, что других плагинов нет.

## Диагностика

Журнал запуска находится в `BepInEx\LogOutput.log`. Неизвестные английские строки, встретившиеся во время игры, записываются в:

`BepInEx\plugins\CrystalCavesHD.Russian\missing-strings.tsv`

Этот файл удобно приложить к сообщению об ошибке вместе со скриншотом экрана.
